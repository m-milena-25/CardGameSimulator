# Card Game Simulator

A command-line card game implemented in C.

## Overview

This project is a two-player card game simulation developed in C. The game includes card shuffling, dealing, turn-based gameplay, and card placement according to predefined rules.

The project was developed as a university assignment with a focus on implementing fundamental data structures and dynamic memory management without relying on external libraries.

## Features

- Custom singly linked list implementation
- Stack implementation using linked lists
- Dynamic memory allocation using `malloc` and `free`
- Card shuffling using a linear congruential generator (LCG)
- Two-player gameplay
- Turn-based game logic
- Text-based user interface
- Deck management and card drawing mechanics

## Technical Concepts

This project demonstrates:

- Pointers and pointer manipulation
- Dynamic memory management
- Linked lists
- Stack data structures
- Modular program design
- Game state management
- Algorithm implementation in C
